Physics utilities
=================

``pymadng_utils.physics`` contains particle rest masses and numerically stable conversions between relative momentum deviation ``dp/p`` and MAD-NG's longitudinal coordinate ``pt``. Pass the reference-beam relativistic beta to ``dp2pt`` and ``pt2dp``; accelerator descriptors and MAD-NG interfaces provide beam-aware wrappers.
